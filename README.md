# powerbi-superstore-dashboard
📌 Descripción del proyecto:

Dashboard interactivo construido en Power BI Desktop para analizar ventas, ganancias y clientes de una tienda "Superstore". A diferencia de mis proyectos anteriores (SQL y Excel), aquí las 8 preguntas de negocio no se responden por separado, sino que viven juntas en un solo dashboard filtrable en tiempo real.

Este es mi tercer proyecto de portafolio como parte de mi transición hacia Data Analytics — mismo dataset que en mis proyectos de SQL y Excel, para comparar resultados entre las tres herramientas.

🛠 Herramientas utilizadas
Power BI Desktop

📊 Dataset
Superstore Sales Dataset (Kaggle) — información de órdenes, productos, clientes, ventas y ganancias de una tienda minorista entre 2014 y 2017.

📈 Componentes del dashboard
3 tarjetas KPI: Ventas totales, Ganancia total, Órdenes totales
Gráfica de barras: ventas por categoría de producto
Gráfica de barras: ganancia por región
Gráfica de líneas: tendencia de ventas por año
Tabla: top 10 clientes por ventas
Filtro interactivo (slicer): por región — al seleccionar una región, todo el dashboard se actualiza automáticamente

💡 Hallazgos principales
Technology es la categoría con más ventas ($836,154), seguida de Furniture y Office Supplies.
La región West genera la mayor ganancia ($108,418) y también el mayor número de órdenes.
Sean Miller es el cliente que más ha gastado ($25,043).
Las ventas muestran una tendencia de crecimiento constante de 2014 a 2017.

Estos resultados son consistentes con los obtenidos en los proyectos equivalentes de SQL y Excel.
